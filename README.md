# Warehouse & Fulfilment SQL Analysis

## About
A SQL project analysing warehouse, order and product data using PostgreSQL.

The project focuses on:
- warehouse performance
- high-value orders
- product demand
- average order value
- high-demand, high-value products

## Tools
- SQL
- PostgreSQL
- VS Code
- Git
- GitHub

## Project Questions
1. Which warehouses process the highest-value orders?
2. Which products appear in the highest-value orders?
3. Which products are most in demand?
4. Which products are associated with the highest average order value?
5. Which products combine strong demand with high order value?
